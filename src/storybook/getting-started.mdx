# Getting Started

This Storybook provides full API documentation, interactive examples, and code references for every component. For design guidelines, usage rules, and component rationale, see the [Reapit Design System](https://design.reapit.com.au).

## Installation

Elements is an ESM-only library available for installation via NPM and your preferred package manager:

<Source
  code={`
# npm
npm install @reapit/elements

# yarn

yarn add @reapit/elements

# pnpm

pnpm add @reapit/elements

# bun

bun add @reapit/elements
`}
language="bash"
/>

## Importing components

<Source
  code={`
import { Button } from '@reapit/elements/core/button'
`}
  language="typescript"
/>

Also import the stylesheet at your application's entry point:

<Source
  code={`
import '@reapit/elements/dist/index.css'
`}
  language="typescript"
/>

Or in a CSS file:

<Source
  code={`
@import '@reapit/elements/dist/index.css';
`}
  language="css"
/>

## Using components

All components accept the native HTML props of their underlying element and forward them via `{...rest}`. For TypeScript users, this behaviour is strongly typed. The only peer dependencies are `react` and `react-dom`.

## Browser support

Elements targets [Baseline 2024](https://web.dev/baseline). See the [Design System documentation](https://design.reapit.com.au) for details.

## Migrating from v4

Elements v5 removes deprecated props and CSS classes that carried `console.warn` notices in v4. Review the [Changelog](?path=/docs/changelog--docs) for the full list of breaking changes before upgrading.
