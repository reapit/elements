# Writing Clear Prose

## Overview

This skill applies William Strunk Jr.'s _The Elements of Style_ (1918) principles to ensure clear, concise writing.

## When to Use This Skill

Use this skill whenever you write prose for humans:

- Documentation, README files, technical explanations
- Commit messages, pull request descriptions
- Error messages, UI copy, help text
- Code comments for complex logic
- Reports, summaries, or any explanation

**If you're writing sentences for a human to read, use this skill.**

## British English Requirement

**All prose MUST use British English spelling and conventions.**

Common British English spellings:

- colour (not color)
- analyse (not analyze)
- organise (not organize)
- realise (not realize)
- centre (not center)
- favour (not favor)

**Note:** Code identifiers may use American English if required by external APIs or conventions.

## Essential Rules at a Glance

### Elementary Rules of Usage (Grammar/Punctuation)

1. Form possessive singular by adding 's
2. Use comma after each term in series except last
3. Enclose parenthetic expressions between commas
4. Comma before conjunction introducing co-ordinate clause
5. Don't join independent clauses by comma
6. Don't break sentences in two
7. Participial phrase at beginning refers to grammatical subject

### Elementary Principles of Composition

8. One paragraph per topic
9. Begin paragraph with topic sentence
10. **Use active voice** - "The system encountered an error" not "The error was encountered"
11. **Put statements in positive form** - "forgot" not "did not remember"
12. **Use definite, specific, concrete language** - "It rained every day for a week" not "unfavourable weather"
13. **Omit needless words** - "whether" not "the question as to whether"
14. Avoid succession of loose sentences
15. Express co-ordinate ideas in similar form
16. **Keep related words together** - "He found only two errors" not "He only found two errors"
17. Keep to one tense in summaries
18. **Place emphatic words at end of sentence**

### Common Mistakes

- Use "data" as plural (these data, not this data)
- Use "less" for quantity, "fewer" for number
- Use "different from" (not "different than")
- Use "whether" alone (not "as to whether")
- Use "like" for nouns, "as" for clauses

## Quick Self-Edit Checklist

When revising prose:

- [ ] Active voice where possible
- [ ] Positive form (avoid unnecessary "not")
- [ ] Concrete, specific terms instead of vague generalities
- [ ] No needless words or phrases
- [ ] Related words kept together
- [ ] Emphatic words at sentence end
- [ ] One topic per paragraph
- [ ] Proper punctuation of independent clauses
- [ ] British English spelling throughout
